# Goodlane Freight Dataset

## Files

| File / Folder | Description |
|---|---|
| `carrier_emails.json` | 274 inbound carrier emails |
| `carrier_profiles.json` | 48 carrier master records |
| `loads.csv` | 50 loads (open, covered, delivered) |
| `rate_history.csv` | Weekly lane rates (Dec 2025–May 2026) |
| `call_recordings/` | 55 WAV broker–carrier calls |

## Notes

- MC numbers and load references may be missing, inconsistent, or wrong
- Call recordings may have garbled spoken IDs
- Some load weights and pickup windows are blank
- Carrier profiles may have expired insurance or non-active authority
